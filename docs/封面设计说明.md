# 封面与封底设计说明

本次封面采用米白、墨绿与奶黄配色，统一封面和封底的 21 mm 左侧对齐线。
中文标题使用微软雅黑粗体，辅助文字使用微软雅黑常规体，英文使用 TeX Gyre Heros。
图文以固定页面坐标排版，解决原封面顶部文字落在色带边缘的问题。

奶蛙形象取自本项目已有参考资料 `ref/img/fig-006-021.jpg`。
按照“尽量复现真实样貌”的要求，仅移除背景、处理边缘并调整版面尺寸，
保留原图的体型、表情、捧腹姿态及光影；原始 JPEG 不作改动。
来源与相关权利归属已记录在教材版权页。封底补充了内容简介、三个研读方向与适用对象。

## 成品

- `output/pdf/奶龙学导论_封面优化版.pdf`：当前源码编译出的完整教材，首尾为新版封面和封底；当前快照为 110 页。
- `output/pdf/奶龙学导论_封面与封底.pdf`：两页独立封面文件。
- `output/covers/封面.png`、`output/covers/封底.png`：300 dpi 页面图像。
- `output/covers/封面与封底预览.png`：用于快速查看的并排预览。
- `output/封面导出检查.txt`：导出与文字一致性检查记录。

## 可编辑源文件

- `frontmatter/cover.tex`：封面图文、背景与配色位置。
- `backmatter/backcover.tex`：封底文案与版面。
- `style/cover.tex`：独立封面样式，不修改原正文共享样式。
- `covers.tex`：独立封面文档入口。
- `figures/cover_naiwa_cutout.png`：带透明通道的原貌素材。
- `tools/prepare_cover_asset.py`：可重复执行的原貌抠图脚本。
- `tools/export_cover_outputs.py`：输出 PDF、300 dpi 页面图像及预览。

`main.tex` 已接入封面、封底。`build/cover-work/before/` 是本地历史备份，
不属于当前成品，也不应作为导出或上传依据；当前成品始终以最新源码重新编译。

## 再次导出

在项目根目录执行现有 `build.ps1` 重编整本教材；独立封面执行两遍：

```powershell
xelatex -interaction=nonstopmode -halt-on-error -output-directory=build covers.tex
xelatex -interaction=nonstopmode -halt-on-error -output-directory=build covers.tex
python tools/export_cover_outputs.py
```

Python 导出需要 Pillow、NumPy 与 pypdf，`pdftoppm` 需在 PATH 中。
如修改书名、编写组或版本信息，请同步修改 `main.tex` 和 `covers.tex` 中的书籍信息宏。
页面按现有书稿保持 A4；独立封面为单页成品尺寸，未设书脊、裁切标记或印厂出血。
