# 《奶龙学导论》编写体例规范（v1.0，冻结）

> **本文件对所有章节作者具有约束力。** 共享宏层 `style/nailong.sty` 已冻结，
> 章节文件**不得**再 `\usepackage`、不得重定义已有宏、不得修改 `main.tex` 与 `nailong.sty`。
> 需要新增宏的，写在章节文件顶部的注释里，由主编统一并入。

---

## 一、项目结构与写作边界

```
奶龙教材/
├── main.tex                     ← 主编维护，勿动
├── style/nailong.sty            ← 共享宏层，冻结，勿动
├── refs/references.bib          ← 主编维护；需要新文献请在交付说明中列出 BibTeX
├── figures/                     ← 插图（TikZ 源码放在 figures/ 下的 .tex 或直接写进正文）
├── chapters/chNN_xxx.tex        ← 章节正文（每位作者只写自己分到的文件）
├── frontmatter/, backmatter/    ← 主编维护
├── docs/体例规范.md              ← 本文件
└── docs/事实手册.md              ← 事实口径与可信度，写作前必读
```

**写域互斥**：一位作者只写自己名下的 `chapters/chNN_*.tex`。不得触碰他人章节文件。
若发现他人章节有错，不要直接改，写进交付说明交给主编。

## 二、教材结构骨架（每章必须遵守）

每一章按下列顺序组织，缺项要在交付说明里解释原因：

```latex
\chapter{章名}\label{ch:xxx}

\begin{nlkeypoints}
  \begin{enumerate}[label=(\arabic*),leftmargin=2.4em]
    \item 要点一（一句话，可判定）
    \item 要点二
    \item 要点三
  \end{enumerate}
\end{nlkeypoints}

%% 章首导语：200～400字。交代本章要回答什么问题、用什么材料、结论是什么。
%% 不写“本章将介绍……”这种空话，直接给出问题与立场。

\section{第一节标题}
...
\section{本章小结}
（总结，300～600字，回扣章首提出的问题，指出未决问题）

\begin{nlexercises}
  \item 习题一（要有明确作答要求，避免“谈谈你的看法”式空题）
  ...
\end{nlexercises}

\nlkeywords 术语A、术语B、术语C
```

**每章规模**：正文（不含习题）不少于 6000 汉字；核心章（第 3、4、6、7 章）不少于 9000 汉字。
宁精不滥：每一节都要有可核查的材料或明确的论证步骤，不写填充式排比句。

## 三、"教材味"的具体要求

教材与网文、公众号文章的区别，体现在以下六条上，请逐条对齐：

1. **概念先行**。每引入一个新术语，用 `\term{...}` 标注，并在首次出现处给出可操作的定义
   （"在此后的讨论中，X 指……；与之相区别的 Y 指……"）。定义的判据要能落到可观察现象上。
2. **分层展开**。一个机制/分类若有多层，先给总框架（配表或 TikZ 图），再逐层展开，最后回扣框架。
3. **史论分开**。叙述事实用陈述句并给出处；提解释、提模型时明确写"本书认为""一个可能的解释是"。
   绝不用叙述语气把推测写成事实。**这是本书最硬的纪律。**
4. **可复现的方法**。凡涉及统计、编码、分类的操作（如"衍生语空耳等价项的判定"），
   要写清判定标准、样本来源、计数规则，让读者能自己重做一遍。
5. **批判性距离**。研究对象的娱乐性不等于文本可以放弃学理。凡涉及玩梗、调侃，
   一律放进 `nlcritique` 框并明确标记；同时要至少指出该现象被批评的理由（盗版、骚扰、审丑等），
   不做单向吹捧。**不写人身攻击、不写对具体个人的健康/生死类推测。**
6. **教学友好**。每章至少 1 张自制图表（TikZ / booktabs 表格）；每章至少 2 处
   `\begin{example}` 或 `nlcase` 案例；关键结论用 `\keyw{}` 加重。

## 四、可用环境与宏（白名单）

### 结构
| 用途 | 写法 |
|---|---|
| 章 / 节 | `\chapter{}` `\section{}` `\subsection{}` `\subsubsection{}` |
| 术语标注（自动进索引） | `\term{奶蛙}` |
| 无衬线术语 | `\tsm{AIGC}` |
| 外文原文 | `\en{meme}` |
| 加重结论 | `\keyw{关键句}` / `\NL{强调}` |
| 文件名/代码 | `\fname{main.tex}` |
| 可信度标注 | `\conf{A级}` |
| 时间线条目 | `\tl{2020-01-22}{奶龙 IP 在短视频平台正式上线}` |
| 尾注式小字 | `\srcnote{资料来源：……}` |

### 彩色框（**必须用，不要用 `\fbox` 或自定义框**）
```latex
\begin{nltermbox}{术语：迷因（meme）} ... \end{nltermbox}
\begin{nlhistory}[史料与考据] ... \end{nlhistory}
\begin{nlmethod}[研究方法提示] ... \end{nlmethod}
\begin{nlcritique}[批判性反思] ... \end{nlcritique}
\begin{nlcase}[案例 4-1：……] ... \end{nlcase}
\begin{nlkeypoints} ... \end{nlkeypoints}
```

### 定义—命题—例 的教材骨架
```latex
\begin{definition}[迷因的复制子定义]\label{def:meme}
  ...（定义正文，可以含公式）
\end{definition}

\begin{proposition}\label{prop:xxx}
  ...
\end{proposition}
\begin{proof}
  ...
\end{proof}

\begin{example}
  ...
\end{example}

\begin{hypothesis}\label{hyp:xxx}
  ...
\end{hypothesis}
```
编号自动按章重置，引用写 `\ref{def:meme}`。
**注意**：`hypothesis` 一律用于"本书提出、尚未经验检验"的命题，正文必须显式说明其未经验证。

### 公式
用 `amsmath` 的 `equation` / `align` / `gather`；行内用 `$...$`。
中文上下文中出现的变量符号用数学模式；纯中文不要塞进 `$`。

### 表格
```latex
\begin{table}[htbp]\centering
  \caption{标题}\label{tab:xxx}
  \begin{tabularx}{\textwidth}{@{}lXX@{}}
    \toprule
    列一 & 列二 & 列三 \\ \midrule
    ... \\ \bottomrule
  \end{tabularx}
\end{table}
```

### 图（一律自制 TikZ，**禁止**插入受版权保护的原始动画截图）
```latex
\begin{figure}[htbp]\centering
  \begin{tikzpicture}[...] ... \end{tikzpicture}
  \caption{标题}\label{fig:xxx}
\end{figure}
```
若确需引用网络图片，**只能**放进附录 D 的"资料来源"表里以文字列出，
并且必须写明权利人未授权、仅作引用记录。**不得**在正文中嵌入。

### 引用
- 上标数值引用：`\cite{shifman2013memes}` 或 `\cite{shifman2013memes,dawkins1976selfish}`
- 只允许引用 `refs/references.bib` 中**已存在**的 key。需要新文献 →
  在交付说明里给出完整 BibTeX，不要自己改 .bib。
- 网络来源用脚注给出完整 URL 与访问日期：
  `\footnote{\url{https://...}（访问日期：2026-10-12）。}`

## 五、语言与文体

- **人称**：用"本书""我们"，不用"笔者""本文"（除非在方法论说明处）。
- **语体**：书面学术语体 + 克制的幽默。幽默只允许出现在：框标题、脚注、`nlcritique` 框、
  以及被明确标记为"社群用语"的引述中。正文主干保持中性。
- **标点**：中文全角标点；引号用中文引号""''；破折号用 `——`；数字与英文用半角。
- **数字**：统计数字用阿拉伯数字（3800 万、80 亿次）；序数、成语、称谓用汉字（第一章、五重）。
- **专有名词统一写法**（务必照抄）：奶龙、奶蛙、捧腹大笑、第七印象文化传媒（深圳）有限公司、
  小七、暴暴龙、星野 AI、纲手【百豪】、B 站（哔哩哔哩）、抖音、小红书、AIGC、UGC。
- **社群用语**：必须在首次出现时加引号并解释，例如："糖"（社群用语，指内容幼稚、尬感强）。
- **禁止**：网络脏话、地域歧视、对具体个人的侮辱性外号、对真实个人健康或生死的推测、
  未标注来源的具体数字。这几条是硬红线。

## 六、可信度分级（写作前必读 `docs/事实手册.md`）

| 级别 | 含义 | 写作方式 |
|---|---|---|
| **A** | 一手权威来源（人民日报、官方公告、同行评议论文） | 可直接作事实陈述并 `\cite` |
| **B** | 机构/平台公开信息、可检索的媒体报道 | 可作事实陈述，注明来源与日期 |
| **C** | 社群考据、二手评述、口述历史 | **只能**写成"据社群考据""有说法认为"，并说明其不确定性；不得作为论证前提 |
| **M** | 本书自建的"教学模型"、示例数据 | 必须显式标注"本书构造的示例""非经验数据" |
