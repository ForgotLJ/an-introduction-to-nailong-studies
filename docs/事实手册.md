## 二、奶蛙传播史（多为 C 级，必须谨慎表述）

### 2.1 形象起源

| 事实 | 级别 | 表述建议 |
|---|---|---|
| 2024-10-02，星野 AI 用户"纲手【百豪】"创建"奶龙"智能体（ID `zNCvQDKfXy`），使用平台 AI 生成的角色头像即为最初奶蛙形象 | C | "据失传媒体中文维基等社群考据词条记载" |
| 该形象因 AI 渲染导致体型畸变：腹部膨大、四肢细小，形似青蛙，故得名"奶蛙" | C/B | 形象特征的描述可作事实；得名过程写"社群因此称之为" |
| 奶蛙最初被误认为与抖音博主"季洪行"视频的 AI 融合产物（2024-03-07 起有此说法） | C | 作为"误指"案例写入，体现考据的曲折 |
| 2026-08-04，B 站用户"雾蚀心忘症"在星野 App 中找到符合形象的智能体并发布评论 | C | 同上 |
| 2026-08 前后，以 B 站 UP 主"看仙碎"为代表的一批爱好者推进了起源考据（第一版教材记录视频号 BV1ndMk65EwM） | C | 第一版教材口径，可引为"社群考据的代表性成果" |
| 该智能体现已无法搜索、分享，评论区关闭 | C | 说明"不可复核性"这一方法论难题 |
| 失传媒体维基自陈：词条标记为"待改进""来源缺失"，且"星野 App 出现 bug"的结论**仅为推测、缺乏直接证据** | C | **这一句必须写进教材**，是讨论网络考据可靠性的绝佳材料 |

### 2.2 关于创作者本人的处理原则（硬红线）

- 社群已形成共识：**创作者本人不愿被公开指认**，公开指认可能给其带来法律与舆论风险。
- 存在以"最残酷的结局"为标题的二手评述文章，其中含**对个人境况的推测性表述**。
- **本书写法**：只陈述"考据指向某个匿名用户，且该用户未公开认领这一形象；
  出于对当事人的保护，本书不对其身份与个人境况作任何推断或披露"，
  并将其作为**网络考据伦理**的教学案例（第 12 章）。**不得**转述任何关于其健康、生死的内容。

### 2.4 常见变种谱系（第一版教材整理，B/C 级）

**换皮奶蛙**（保留大部分形体特征，仅皮肤变化）
- 异色奶蛙
- "植奶""僵奶"：B 站 UP 主"暖气杀手 AAA"《植奶大战僵龙》系列（奶蛙 ×《植物大战僵尸》）
- 其他：线代课本奶蛙、VIVO 奶蛙、学习通奶蛙等（以图标、封面换皮）

**异形奶蛙**（丢失大量形体特征，保留眼睛与大笑）
- **奶蛋**：奶蛙简化到极致的产物；B 站 UP 主"奶史_"《选择你的奶伴》系列高频出现；
  与衍生语"安迪"结伴，因胜率高而产生"奶蛋轮椅"说法（"安迪"空耳为"俺无敌"）
- 奶狗、奶鸡、奶鼠、奶茶、豆奶等（多出自《选择你的奶伴》系列）
- **奶蛙娘**：经典娘化形象；因奶蛙手为黑色，奶蛙娘的手亦为黑色
- 其他：物化奶龙，如"奶菜"

**主要客串角色**
- 美团袋鼠（伪装成美团袋鼠的奶蛙）
- 牛来、牛来妈

**衍生语**（第一版教材整理）

| 衍生语 | 主要运用场景 | 等效空耳 |
|---|---|---|
| 安迪 | 爬行奶龙说话、奶蛋说话、奶蛙出场 | 俺滴、安定、俺无敌、暗地 |
| 嘎嘎滴辣虾 | 运用场景广泛，高频说话效果 | 刚刚点了谁、刚刚跌落水、刚刚掉了什 |
| 卡脚先 | 小剧场的转折或收尾 | 刚救下、赶紧写、干啥先 |
| 无了 | 吃瘪、惊讶音效 | 哦了、好了 |
| 甘巴爹 | 肯定、疑问音效 | 干扒地、刚拔的 |
| 有用不 | 丰富语言，一般作"安迪"的下位替代 | 忧郁菇、犹豫不 |

**衍生动作**：思考、蹲起大笑（另有双人组合技，第一版"按下不表"）、爬行（爬到一半看向屏幕说"安迪"）、摆架势。

> **学术化处理建议**：把"衍生语"重新表述为**空耳词（soramimi）驱动的语音梗**，
> 即"语音外壳保留、语义外壳被重新指派"的双层结构。空耳等价项的判定标准必须写清楚：
> (1) 音节数与声韵母近似；(2) 在社群使用中形成稳定搭配场景；(3) 有可检索的二创实例。
> 这套标准正是第 8 章的"可复现方法"。

## 五、本书自建的教学模型（M 级，必须显式标注）

以下模型**不是**经验事实，是为了让分析可操作而构造的脚手架。
正文中必须写"以下为本书构造的教学模型"。

1. **奶蛙迷因传播的 SIR 型模型**（第 6 章）：把受众分为未接触者 S、传播者 I、疲劳者 R。
   用于说明"为什么热度终会衰减、以及为什么会二次爆发"。参数取值为示意值。
2. **五重机制分析矩阵**（第 7 章）：把第一版教材提出的五种机制
   （情绪代偿、群体稀释、反精致、校园社交、逆反认证）重写为
   **"压力源—补偿行为—可观察指标—竞争性解释"** 四列结构，使其可检验。
3. **空耳词的语音距离指标**（第 8 章）：用拼音声韵母编辑距离近似音节相似度，
   仅为排序用，不作为音系学结论。
4. **立牌活动的协商强度谱**（第 11 章）：按"校方反应—学生反应—是否留下持久物"三维给案例分级。

## 六、必须避免的写法（清单）

1. ❌ 把 C 级社群考据写成确定事实。
2. ❌ 把两个不同来源的数字合并（如把 3800 万与 3900 万写成一个数）。
3. ❌ 转述任何关于具体个人健康、生死、私德的推测。
4. ❌ 嵌入受版权保护的动画截图、表情包原图、周边商品图。
5. ❌ 使用侮辱性外号或地域、性别、学校歧视表述。
6. ❌ 用"显然""众所周知"代替论证。
7. ❌ 把本书构造的模型说成实证发现。
8. ❌ 只讲乐子不讲批评：每章涉及争议现象时必须写出反对意见。
